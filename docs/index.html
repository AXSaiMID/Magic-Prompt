Gere o prompt do site do seu cliente

O sistema reúne modelos prontos por segmento e transforma os dados do cliente em um prompt detalhado, pronto para a IA que vai criar o site.

  1. Escolha o segmento do cliente e o objetivo do site.
  2. Preencha os dados da empresa, redes, identidade visual e conteúdo.
  3. Envie logo, imagens e vídeos (opcional, mas recomendado).
  4. Copie o prompt e baixe a pasta completa do cliente em .zip.
